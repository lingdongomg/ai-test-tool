## 交互流程

### 从分析任务学习知识

```mermaid
graph TD
    A[点击「从日志学习」] --> B[打开对话框 - Tab1]
    B --> C[加载已完成任务列表]
    C --> D{选择任务}
    D --> E[设置自动审核开关]
    E --> F[点击「开始学习」]
    F --> G[按钮显示 loading]
    G --> H{API 调用}
    H -->|成功| I[关闭当前对话框]
    I --> J[打开学习结果对话框]
    J --> K[展示提取的知识列表]
    K --> L[用户关闭结果对话框]
    L --> M[刷新知识列表+统计]
    H -->|失败| N[显示错误 Toast]
```

### 上传日志文件学习

```mermaid
graph TD
    A[点击「从日志学习」] --> B[打开对话框 - Tab2]
    B --> C[拖拽或点击上传文件]
    C --> D{文件验证}
    D -->|类型不对| E[Toast: 仅支持 .log/.txt/.json]
    D -->|通过| F[显示文件名]
    F --> G[填写来源说明（可选）]
    G --> H[点击「开始学习」]
    H --> I[上传文件 + 显示 loading]
    I --> J{API 响应}
    J -->|成功| K[关闭对话框 → 打开结果对话框]
    J -->|失败| L[显示错误信息]
```

### 日志源管理

```mermaid
graph TD
    A[进入日志源页面] --> B[加载日志源列表]
    B --> C[显示列表和统计]

    C --> D[点击「新增日志源」]
    D --> E[打开表单对话框]
    E --> F[填写配置]
    F --> G[点击保存]
    G --> H{API 创建}
    H -->|成功| I[关闭对话框 + 刷新列表]
    I --> J[显示 WebSocket URL]
    H -->|失败| K[显示错误]
```

## 组件接口定义

### LogLearnDialog（从日志学习对话框）

| Props | 类型 | 必填 | 说明 |
|-------|------|------|------|
| visible | boolean | 是 | 对话框可见性（v-model） |

| Events | 参数 | 说明 |
|--------|------|------|
| update:visible | boolean | 关闭对话框 |
| learn-success | LearnResult | 学习成功，携带结果数据 |

### LearnResultDialog（学习结果展示）

| Props | 类型 | 必填 | 说明 |
|-------|------|------|------|
| visible | boolean | 是 | 对话框可见性（v-model） |
| result | LearnResult | null | 是 | 学习结果数据 |

| Events | 参数 | 说明 |
|--------|------|------|
| update:visible | boolean | 关闭对话框 |
| close | void | 关闭事件（触发列表刷新） |

## 交互状态

| 元素 | 默认 | 加载中 | 空状态 | 错误 |
|------|------|--------|--------|------|
| 任务选择器 | 下拉列表展示任务 | 加载中... | "暂无已完成的分析任务" | "加载失败，点击重试" |
| 文件上传区 | 拖拽上传提示 | 上传进度条 | - | "上传失败：{原因}" |
| 学习按钮 | 蓝色主按钮 | Spinner + "学习中..." | - | - |
| 结果列表 | 表格展示条目 | - | "未提取到知识" | - |
| 日志源列表 | 表格展示 | 骨架屏 | "暂无日志源，点击新增" | "加载失败" |
| 连接状态 | 🟢已连接 / 🔴已断开 | - | - | - |

## 响应式适配

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Desktop | >= 1200px | 侧边栏 + 主内容区，统计卡片 4 列 |
| Tablet | 768-1199px | 折叠侧边栏，统计卡片 2 列 |
| Mobile | < 768px | 隐藏侧边栏，统计卡片 1 列，对话框全宽 |

## 设计规范

遵循项目已有的 TDesign 组件库风格：

- 主色：TDesign 默认蓝（`--td-brand-color`）
- 成功：`--td-success-color`
- 警告：`--td-warning-color`
- 错误：`--td-error-color`
- 字体：TDesign 默认字体规范
- 间距：页面 20px 内边距（与现有 `.knowledge-list { padding: 20px }` 一致）
- 卡片间距：20px（与现有 `.stats-row { margin-bottom: 20px }` 一致）
- 表格：使用 `t-table` + stripe 风格（与现有一致）
- 对话框宽度：600-700px（与现有一致）
